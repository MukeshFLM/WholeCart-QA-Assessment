# BUG-001: Catalogue category filter ignored during SKU search

**Defect ID:** BUG-001

**Module:** Buyer – Catalogue

**Severity:** Medium (proposed)

**Priority:** To be assessed

**Status:** Open

**Environment:** Google Chrome – WholeCart Marketplace

**Test Account:** buyer1 – Spice Route Kitchen

## Test Data

- SKU: SKU-0471
- Selected Category: Grains
- Actual Product: Chef's Banana Chips
- Actual Category: Snacks

## Steps to Reproduce

1. Login to WholeCart using buyer1.
2. Navigate to Catalogue.
3. Select Grains from the category dropdown.
4. Enter SKU-0471 in the search field.
5. Click Search.

## Expected Result

No products should be displayed because SKU-0471 belongs to the Snacks category, not Grains.

## Actual Result

The application displays Chef's Banana Chips (SKU-0471), although Grains is selected.

## Evidence

Evidence/Screenshots/BUG-001.png

## Requirement Reference

Catalogue search and category filtering should return products matching the applied search criteria and selected category.

## Status

Open – Awaiting developer investigation.
