BUG TITLE: [PRODUCT IMPORT] Application allows duplicate SKU entries during CSV upload
Severity: Major
 Priority: High


Module: Product Catalogue / CSV Import

Test Scenario: Upload a CSV containing an SKU that already exists in the catalogue.

Test Data:
- Existing SKU: SKU-9002
- Product: Classic Cold Coffee 200ml
- Duplicate SKU: SKU-9002
Expected Result:
The application should reject duplicate SKU entries and display an appropriate validation message.

Actual Result:
The application accepts the duplicate SKU and displays two identical product records with the same SKU (SKU-9002) in the catalogue.

Status: Failed
