**BUG-006: Application Displays Duplicate Products for the Same SKU**

Module: Product Catalogue / CSV Import
Severity: Medium
Priority: High
Status: Open

Description

The application allows duplicate SKU entries during CSV import, resulting in duplicate product records in the catalogue.
Steps to Reproduce
1. Login to WholeCart using seller credentials.
2. Navigate to the Products section.
3. Prepare a CSV file containing an SKU that already exists (SKU-9002).
4. Upload the CSV file.
5. Complete the import process.
6. Navigate to the Buyer Catalogue.
7. Search for SKU-9002.
8. Observe the search results.

**Expected Result**

The application should prevent duplicate SKU entries and display only one product record for each unique SKU.

**Actual Result**

The catalogue displays two identical product records with the same SKU (SKU-9002) and product name (Classic Cold Coffee 200ml).
