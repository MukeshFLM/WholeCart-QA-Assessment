BUG-004: Application Allows Duplicate SKU Entries During CSV Product Import
Module: Product Catalogue / CSV Import
Severity: High
Priority: High
Status: Open
Requirement Reference: Product SKU Uniqueness

1. Description
The application allows sellers to upload a CSV file containing an SKU that already exists in the product catalogue. As a result, duplicate product records with the same SKU are created and displayed in the catalogue.
2. Preconditions
- Seller is logged in to WholeCart.
- Products already exist in the catalogue.
- An existing SKU is available for duplicate testing.
- CSV product import functionality is accessible.
3. Test Data
Field	Value
Existing SKU	SKU-9002
Product Name	Classic Cold Coffee 200ml
Category	Beverages
Duplicate SKU	SKU-9002
Piece Price	₹45.00
Case Size	24
Import Method	CSV Upload

4. Steps to Reproduce
1. Login to WholeCart using seller credentials.
2. Navigate to the Products section.
3. Verify that SKU-9002 already exists in the catalogue.
4. Prepare a CSV file containing the existing SKU (SKU-9002).
5. Navigate to the CSV Import section.
6. Upload the CSV file.
7. Complete the import process.
8. Navigate to the Catalogue.
9. Search for SKU-9002.
10. Observe the displayed product records.
5. Expected Result
The application should validate SKU uniqueness during CSV import.

If the SKU already exists, the application should reject the duplicate entry and display an appropriate validation message.

The catalogue should maintain only one product record for each unique SKU.
6. Actual Result
The application successfully accepts the CSV upload containing an existing SKU.

The Catalogue displays two identical product records with the same SKU (SKU-9002) and product name (Classic Cold Coffee 200ml).

No duplicate SKU validation message is displayed.
7. Business Impact
- Duplicate product records create catalogue inconsistencies.
- Buyers may encounter duplicate products during product searches.
- Sellers may face difficulties managing product inventory.
- Duplicate SKUs can cause incorrect stock and order tracking.
- Product identification and reporting accuracy may be affected.
8. Evidence
- BUG-004-Duplicate-SKU.png – Catalogue showing two identical product records with SKU-9002.
9. Requirement Reference
Product SKU Uniqueness: Each product should have a unique SKU. The application should prevent duplicate SKU entries during product creation and CSV import.
