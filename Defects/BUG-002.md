# BUG-002: Checkout allows seller sub-order below ₹2,000 when multiple sellers are involved

**Module:** Buyer – Checkout

**Severity:** High (proposed)

**Priority:** High (proposed)

**Status:** Open

**Requirement:** CR-07

**Test Account:** buyer1 – Spice Route Kitchen

### Preconditions
The buyer has products from two different sellers in the cart.

### Test Data

| Seller | Net amount |
|---|---:|
| FreshFarm Foods | ₹13,199.67 |
| WholeCart Direct | ₹367.96 |

### Steps to Reproduce

1. Login as buyer1.
2. Add products from FreshFarm Foods worth more than ₹2,000.
3. Add products from WholeCart Direct worth less than ₹2,000.
4. Open the cart and proceed to checkout.
5. Select a valid delivery date and slot.
6. Click Place order.
7. Navigate to Order History.
8. Verify the generated seller sub-orders.

### Expected Result

The checkout should be rejected because WholeCart Direct has a net order value of only ₹367.96, which is below the required ₹2,000 minimum per seller.

### Actual Result

The application successfully creates orders for both sellers, including a WholeCart Direct sub-order worth ₹367.96 net.

### Evidence

Evidence/Screenshots/BUG-002

### Requirement Reference

CR-07: Minimum order raised to ₹2,000 net per seller.

### Business Impact

Buyers can bypass the minimum order restriction by combining products from multiple sellers in a single checkout.
